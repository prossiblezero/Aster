A Aster 工程阅读
CODING AGENT HARNESS / 课程 00–15

跟着一次任务，读懂 Aster。

面向会 Python、尚未系统理解 Coding Agent Harness 的读者。沿真实 Runtime 和工具源码，拆开一次任务如何被观察、执行、验证、恢复和评测。

从第 00 章开始 →查看学习路线

你需要什么，最后会得到什么

前提

能读 Python 函数、类和字典。遇到 async，只需先理解为可能等待模型、进程或用户。

读法

每章从具体问题出发，沿当前源码看数据流，再运行离线实验，最后回答练习中的为什么。

成果

能够解释工具调用、权限沙箱、上下文治理、证据归档、记忆、恢复和评测边界。
