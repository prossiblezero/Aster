# Aster 教学网站：交付任务与验收约定

本任务由 Aster 自己执行。操作员负责配置、记录与独立验收，网站实现由 Aster 生成。

目录整理后，以下可复用任务约定采用当前 `learn_web/` 路径；2026-09-17 原运行使用的 `website/` 请求原文保留在 `learn_web/artifacts/website-build/`，未改写原始轨迹。

## 读者与目标

面向会 Python、尚未系统理解 Coding Agent Harness 的读者。让读者从跑通一次任务开始，沿真实源码理解工具调用、权限、上下文、恢复、记忆和评测，最后能够解释设计取舍并运行教程实验。

成品是一套可持续阅读的中文课程网站。内容主体来自 `docs/learning/00-*.md` 到 `15-*.md` 的完整教程，结合当前 `src/aster/` 核对关键行为。不能只生成项目宣传首页、章节标题或短摘要。

## 参考网站中要借鉴的部分

- https://caomaolufei.github.io/AIInfraGuide/ ：首页展示知识模块，模块页有清晰的章节层级、学习顺序与前置要求；内容围绕具体机制和代码展开。
- https://meko1.github.io/llm-interview-guide/ ：清晰的新手入口，左侧分组导航、正文、本页目录的阅读布局，搜索、明暗主题、代码块和上一篇/下一篇；文章解释“为什么”，并安排追问。
- 借鉴信息架构和阅读体验，使用 Aster 自己的视觉风格、内容和标识。不复制对方文章、品牌或统计数字。

## 必须交付

所有新增文件放在 `learn_web/`，不要修改其外的任何文件。

1. 入口 `learn_web/index.html`，支持部署到任意 GitHub Pages 项目子路径，所有站内资源和页面链接使用正确的相对路径。站点是无需服务端的静态文件，直接打开入口也应能阅读正文和导航；静态 HTTP 服务下全部功能可用。
2. 首页：明确读者前提、学习成果、开始学习入口、00–15 章完整学习路线、上下文/安全/记忆三条专题路线、从请求到工具结果的架构导览。视觉干净，适合长期阅读，不堆砌宣传口号和无依据的能力数字。
3. 16 章独立、完整的课程页面。保留原教程的解释、源码节选、可运行实验、预期结果和练习，不将正文压成摘要。保留原文已有的引用和限制。可通过构建器转换现有 Markdown，使用现成 Markdown 解析库，不必手写通用 Markdown 解析器。
4. 章节阅读体验：分组侧栏及当前章节状态、本页目录和锚点、上/下一章、可读代码高亮与复制按钮、合适的正文宽度和行距、表格/代码水平滚动、明暗主题并记住选择；移动端可展开目录，页面本身不横向溢出。
5. 搜索：搜索标题和正文，结果可定位到对应课程页面；搜索数据本地提供，不依赖外部搜索服务。支持键盘操作和 Escape 关闭，有空结果说明。
6. 学习进度：读者可以手动标记章节完成，刷新后保留，可从上次阅读处继续。进度存储失败不得导致正文不可读。
7. 图示必须能帮助理解机制。关键架构图应可直接阅读；原文 Mermaid 若采用浏览器渲染，要有可读降级，不允许只留下报错框。不要在教学正文展示未处理的模板占位符。
8. 源码引用：本仓库尚无配置的 Git remote，不要编造 GitHub 仓库地址。为引用的源码提供站内可阅读副本或带行号的源码页，并提供原始相对路径；教程中的 `.md` 链接要改写为有效页面或明确提供原文件下载。正文不能依赖本机绝对路径。
9. `learn_web/README.md`：本地阅读、重建、测试和 GitHub Pages 部署方法。提供 `.nojekyll`。如果给 Actions 示例，放在 learn_web 内作为可复制模板；不执行 Git push 或线上发布。
10. 网站检查：在 `learn_web/` 内提供 pytest 或 unittest 检查，验证16章存在且有实际正文、静态资源/本地链接/锚点有效、源码引用存在、部署子路径不被站点根绝对链接破坏。用 `run_tests` 执行这些站点检查；只跑原 Aster 工程测试不能代替网站验收。

## 内容准确性

- 先读 README、课程目录和配置/实现说明，再沿需要解释的关键源码核验。
- Aster 已实现 Harness 与 rollout 接口，尚未实现 SFT/GRPO；Memory/Dream 是确定性证据维护，不能写成模型训练或自主学习算法。
- 区分脚本动作回放、工程测试与真实模型评测；不得把开发题36/36写成通用成功率，把首请求压缩率写成总费用下降。
- 当前 CLI/TUI 每次提交是新任务；checkpoint 恢复不等于已实现持续多轮聊天。
- 本轮已修复审批期间文件漂移和 Git 忽略文件扫描；如果教程涉及这些行为，请根据当前源码准确说明。
- 页面中的示例必须保持原来的空格、引号、代码缩进。Python 离线实验仍是 Python 实验，不伪装为网页里可以执行真实 Agent。

## 执行条件

- 模型和凭证由宿主配置，禁止读取或输出密钥。
- 工作区是当前 Aster 仓库的隔离副本，可读源码、测试和文档；写入范围只有 `learn_web/`。
- 使用现有 Python 环境。`markdown_it`、`mdit_py_plugins`、`pygments` 可用；网站重建依赖应写清楚。纯 HTML/CSS/JS 适合此任务，不需要 npm 开发服务器。
- 子进程默认禁网，Git 元数据不在工作区。参考站已由操作员阅读，上述说明就是可用设计输入，不必联网抓取。
- 工具调用先读后改；按文件分段生成，避免一个巨大写入消耗全部输出预算。
- 先完成内容和导航闭环，再检查布局与交互。最后给出交付位置、实际执行的检查、未验证部分和已知限制。

## 独立验收

操作员会在浏览器中检查桌面/手机布局、搜索、主题、进度、代码复制和章节导航；抽查运行循环、上下文、审批/恢复、记忆与训练边界。发现问题会交回 Aster 修订并保留每次尝试，不直接替它编写网站代码。
