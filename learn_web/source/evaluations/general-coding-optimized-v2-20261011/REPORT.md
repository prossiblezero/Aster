## 已落地的改动与证据

- **临时目录隔离。** 生产沙箱复用每个命令在项目树之外的临时目录作为 TMPDIR，避免
  嵌套 pytest 项目向上继承仓库的 --strict-markers。回归用例在旧逻辑下失败、修复后通过；
  Landlock 仅额外允许该命令的临时目录，退出后清理。
- **通用验收指引。** 要求追踪共享根因、直接测试相关 API，并检查类型、顺序、组合操作与
  生命周期；明确隔离副本使用相对路径，优先完成实现和回归。未加入任务答案或隐藏断言。
  本轮三个内部完成但独立失败的案例，以及解释器路径失败，说明提示仍不充分。
- **有界故障退避。** 仍最多三次请求，默认等待改为 5/10 秒；数字 Retry-After 上限 60 秒。
  流式与非流式恢复回归均通过。真实运行中 SymPy 23262 遇到一次 503，约 5.011 秒后重试
  返回 200，最终整题通过；这确认机制实际执行过，不能据此推导原短等待必然失败。
- **评测环境适配。** 用 Aster 的 Python 3.12 启动沙箱，任务命令仍用镜像解释器；
  重建 Git 基线时保留原始跟踪但被 ignore 命中的文件，修复 Sphinx egg 夹具丢失。
  Sphinx 9230 本轮约 229 秒正常交付并通过，第一版则超时后独立通过。
- **容器权限与生命周期。** 专用 Docker 任务容器内允许自身进程信号和只读 /proc，
  支持真实子进程终止与 Valgrind；宿主生产沙箱的信号权限未改变。pytest 源码导入和
  gRPC 后台服务沿用已披露的容器适配。异步取消独立检查 6/6 通过；gRPC 的跨调用服务
  仍依赖评测适配，不能称为生产 Aster 原生具备同等持久服务能力。

生产改动涉及四个文件，见 [source.patch](source.patch)。完整工程测试 **1231 通过、4 跳过**，
Ruff 通过；[测试记录](production-tests.txt)和七项[环境预检](environment-preflight.json)已保存。
预检包含 Python 3.6 写入/测试、Sphinx 原生 egg 测试、两道 pytest 环境、真实子进程信号、
Valgrind 启动和 gRPC 跨调用服务存活。正式运行后确认源码、运行器、题面、镜像、模型和预算
均与冻结清单一致，二十题均已判分；任务容器、专用网络和模型网关已退出。
