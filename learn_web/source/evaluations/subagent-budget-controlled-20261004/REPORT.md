# r6 受控委派评测：44 回合完成，采用提前部分交付

2026-10-05 完成。**本轮确实检验了新机制：44/44 回合都启动了真实孩子；r6 的六个压力回合均发送无工具总结请求，六份模型部分报告都被父方接收。** 压力组严格整题通过从 r5 的 0/6 提高到 r6 的 4/6，空答案从 6 次降至 1 次，全队 token 增加 10.2%。正常任务及充足预算对照没有出现总体质量退步，按预登记采用 r6。

主区 55 个生产模块已逐字节匹配本轮冻结候选。相对 r5 只改 Runtime 和 WorkerManager，+21/-10，净增 11 行；没有新增运行依赖、工具、配置或持久状态。硬预算门禁不放宽，PARTIAL 仍是部分交付。未提交、推送或发布。

## 这轮测了什么

比较原冻结 r5 与 r6 两个父子版本，使用原十题、80 个可执行事实和原评分器，不重新估计相对 Solo 的优势。模型配置与实际成功返回标签均为 `gpt-5.6-luna` / Responses，64k 上下文、8192 输出上限，Memory 关闭。

- **从头十题：20 回合。** 每题两版各一次，通过真实 WorkerManager 显式分配第一工作包给一个只读孩子，父方并行完成第二包。每队 36 次模型调用、60 次工具、300,000 token、600 秒。此处检验明确分工的行为，不检验自主拆分。
- **已有证据的压力与充足预算对照：24 回合。** 取 r5 全部三个真实委派案例的成功读取记录：Boltons/1、More Itertools/1、More Itertools/2；每个前缀、每种预算、每版各两遍，第二遍反转顺序。父方读取记录截断于首次收到交付，排除了失败后接管孩子工作的补读。

前缀只重放真实 `read_file`，不提供旧模型答案、隐藏 oracle 或旧 shell 输出。父方与孩子从相同源码读取证据开始，孩子先结束、父方再整合。**这是已有证据条件下的受控交付实验，不是完整历史检查点复演，也不是从头任务的性能。** 历史模型 token 没有计入本轮费用；预读计入工具额度。三个前缀只覆盖两道题，其中两个来自同一道 More Itertools，不能当成六道独立新任务。

压力额度由请求估算预先计算并冻结，分别为 **69,149、54,076、53,679 token**；充足预算为 300,000。两版首次孩子请求都可通过原硬准入，原版仍有调查工具，候选进入提前总结。完整公式、任务顺序、失败处理见 [PROTOCOL.md](PROTOCOL.md)。零模型预检覆盖两版全部十题启动、三个压力条件及三个充足条件，另核验 80 个正确事实与 90 个负对照。

从头十题的 r6 Django 调查出现一次 SSL 服务异常，最终空答案，两次逻辑请求缺失用量。该首次失败完整保留；70/80 不能解释为八个独立推理错误。双方可解析的九对行为事实都是 **70/72**，严格通过配对为 1 胜、0 负、9 平。r5 总量为 1,042,446 token，r6 已知量至少 930,149；只有九对完整用量可比较，合计下降 3.75%，配对比值中位数则为 1.0967。正常组没有触发提前收尾，其分差不能归因于新分支。

充足预算组两版都交付了六份完整子报告，没有空答案，也没有触发提前总结；全队 token 为 318,773 → 319,027，基本持平。此组作为兼容性对照，不把未触发机制时的分数差解释为机制收益。

压力组四胜、零负、两平，token 增加 **25,269（10.15%）**。候选完成了更多交付，但耗时也增加：配对耗时中位比为 2.876，不能宣称速度优势。计时从分工及预读 setup 完成后开始，不包含任务文件准备与前缀预读，因此不是完整从头任务的耗时。

原版六个压力回合全部无最终答案，两版没有双方可解析的压力配对。证据支持的是**预算紧张时的交付可靠性改善**，并未证明更强的推理能力。全部条件的首次结果均保留，没有替换失败、修改评分或按结果调节额度。

## 已知边界与下一步方向

Boltons 两遍都未严格通过。第一遍候选虽交付了四个子答案，父方仍追加五次源码读取；已记账 51,730 加下一请求估计 27,653，超过 69,149，最终没有答案。第二遍候选交卷并答对 6/8；`d4` 的错误值在子报告与父答案中完全相同，另一处 `i3` 错误来自父方工作包。因此不能把“有模型总结”视为“总结正确”，也不能声称父方预算耗尽已解决。

六份提前交付都保持 `delivery=partial`、孩子停止原因 `team_token_limit`，没有伪装为完整完成。五份可按原 JSON 规则解析的子报告覆盖 20 个事实，其中 17 个正确，15 个正确事实在父答案中保留；另两项正确事实因父方空答案无法检验保留。一份 More Itertools 报告带 PARTIAL 说明及代码块，原解析器不接受整段文本，本轮没有修补或重评分；父方接收后仍严格通过八问。不能把自动解析覆盖不足当成事实全错。

本轮提前交付的默认源文均只有同一路径最近的一段 500 字符；父方随后仍有补读。结合预算拒绝轨迹，下一步值得验证的是父方最后一次可负担请求的收尾决策，以及复用已经读取的关键证据片段。这里是后续设计方向，尚未用消融实验证明短摘录导致了全部失败。本轮采用仅限已验证的轻量 r6 改动。

这仍是开发集和受控边界实验，不是独立保留集、统计显著性证据或普遍优于 Solo 的证明。此前十题扩展与 r0–r6 历史结果见[原报告](../subagent-ten-20261003/REPORT.md)；本轮增加 44 回合后累计 284 回合，不把三个不同条件混成一个总体通过率。
