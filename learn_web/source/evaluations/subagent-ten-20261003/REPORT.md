## 数据与比较范围

实际工作区已有六题，本轮保留并新增 Boltons、More Itertools、Cachetools、ItsDangerous 四题，达到 **10 道不同任务、80 个行为事实、7 个固定源码快照**。每题两个工作包、每包四问。见[数据集及恢复命令](../../datasets/subagent-ten-20261003/README.md)。

这是只读源码调查/受限审查，不是代码修复或上游官方 benchmark 成绩。r0–r4 是驱动固定首次分工，r5 才开始测模型自主选择。题目已用于迭代开发，不能称为独立保留集；重复两遍仍是十道不同任务。隐藏答案由外部进程执行探针生成，Agent 只接触源码与无答案的任务请求。

所有组使用相同的 `gpt-5.6-luna`、执行权限和全队上限：36 次模型调用、60 次工具、300,000 token、600 秒；64k 上下文、8192 输出上限，Memory 关闭。每版同时重测 Solo。r2 起每轮预先安排两遍完整对照，第二遍反转组别顺序；失败保留，不用成功重跑替换。r5 的 Solo/team 分别使用 0/1 个自主委派槽并冻结两份配置。完整规则见[协议](PROTOCOL.md)。

## 退步和高成本的具体原因

1. **过大的交付反复重发。** r0 七次交付拒绝中六次超过 4,000 字符。r1 使用共享 8,000 上限后没有超长拒绝，仍保留最多四段、来源归属、已读范围及版本验证；没有自动截断支持代码。
2. **交付内容与最终值不一致。** 原轨迹包括正确解释配错误数组层级、多个符号塞入单符号字段、父方把正确子值改错。父子提示增加了类型、嵌套、顺序、异常和引用契约核对；没有用程序拼接子答案绕过父方判断。
3. **父方重做委派工作。** r2 的 76 个可解析子事实全部正确并被保留，三个 team 行为错误都在父方自己的工作包。父方首次收到子报告前读取的 11,490 行中，有 4,673 行与孩子的实际读取区间重合；逐条轨迹确认了多例无依赖的跨包重复调查。重合本身只是诊断，不把同文件的必要读取全部算作浪费。
4. **协调操作增加模型轮次。** r2 父方 99 次模型调用，另有孩子 82 次；父方调用 status 31 次，包含短轮询，并四次加载已经暴露的 status。每多一轮都再次支付上下文输入。仅提高通信效率或减少一个节点，不能保证总体更经济。
5. **固定每题委派缺少成本取舍。** r4 固定父子分工仍为 15/20，低于同版 Solo 的 16/20，token 配对中位比 2.243。r5 允许模型选择后，17/20 回合自行处理，3 回合委派。它改变了实验策略，不能将跨轮差异单独归因于工具可见性或某条提示。
6. **共享 token 预算可能在答案交付前耗尽。** r5 Boltons/1 的孩子没有模型结论，父方接管重查后也无法支付下一次请求。现有提前 partial 收尾覆盖局部步骤/调用上限，没有按动态 token 余额提前总结；孩子也看不到父方持有的动态团队余额。预算门禁正常拒绝超额请求，但不能保证完成答案。这是仍存在的边界，未通过提高上限隐藏。

## 研究如何落到轻量实现

已阅读固定版本 pi、Codex、OpenHands SDK 的实际实现，以及以 2026 年为主的 ACL、ICLR、ICML 论文和 arXiv 方法正文；来源、会议状态及未核实部分见[调研](RESEARCH.md)和[来源摘要](SOURCES.json)。

- pi 的可消费源码交付：提供精确行段和实现正文，接收者可据此复核；Aster 继续复用现有 EvidenceStore。
- Codex 的消息交付与等待分离：复用原子会话续问、自动交付和 any/all 等待，不引入第二套事件总线。
- AgentSlimming 与 BOAD：按贡献和全队成本删减协作步骤，分别归因子错误、父方修复及错误传播；不建立角色训练池或路由模型。
- LLM-as-Scheduler、MAS-ProVe、Routed Graph Handoff：先检查可验证契约，有具体缺口才修复，不新增常驻 critic。论文各自实验中的收益不等于 Aster 的实测收益。
- pi 直接注册启用的工具入口，启发 r5 直接展示已有 `worker_start`；OpenHands 的阻塞 Task 和 ProgRouter 的进度路由作为取舍参考，未混入冻结 r5。后者需要在线训练与异构模型，不适合为十题引入新服务。

r3 明确父方先完成 `parent_work`，交付后再按缺口复核，并缩小工具加载目录；r4 提示合并独立取证及等待，并执行可运行的精确表达式；r5 在已开启能力时直接展示启动工具，精简重复 schema 说明，使模型自主选择。累计相对本轮初始工作区仅 **五个生产文件 +51/-37，净增 14 行，零新增依赖、工具、配置和持久状态**，见 [r5-candidate.patch](r5-candidate.patch)。默认 `max_workers=0` 继续关闭自主派工；启用后直接展示入口，权限与单写者门禁保留。
