# 会话操作专项协议（运行前冻结）

目标是衡量指定工作流的功能覆盖、操作路径与人工背景输入，不推断模型智力、真实任务成功率或真人操作速度。

基线为 `a3f338b`，候选使用正式运行时冻结的提交和源码摘要。使用 Conda aster；每个版本在单独进程中通过 PYTHONPATH 加载，并核对 aster.__file__。全部模型调用使用离线替身，不发送网络请求。安全、归档、恢复检查和 TUI 命令仍走实际产品实现。

六个工作流：旧历史定位、保留互斥分支、返回历史模型位置、显式带回探索结论、进程重建后恢复、多会话切换。每种准备三个内容变体，新旧两版各一次，共 36 条脚本操作记录。三个变体不是三个使用者；原始日志及所有失败均保留。调试结果写独立目录，不覆盖正式批次。

预置历史和新旧版本共同需要的工作内容不计操作收益。测量区间内记录每次真实命令、选择、背景补充、外部查找及其输入文本。命令提交、选择确认、复制、粘贴各算一次；复制/粘贴的背景作为单独操作，不与正常新需求混合。基线可使用现有 /history、/resume、/model 和多个终端；必须离开产品查找 checkpoint 或手动组织摘要时单列，不强行把不支持的功能换算成无限耗时。

主要结果：脚本工作流完成数、无需外部文件操作的完成数、规定路径操作数、手动背景补充字符数、恢复后状态校验结果。模型调用数只作过程记录，不能解释为真实 API 费用。

人工历史定位耗时、状态辨认正确率、主观便利程度均标记未采集，不由脚本、模型代填。不声称脚本采用的路径是所有用户的最短路径。另提供人工记录表，保留为空即可复用。

本地性能单列：合成 1,000 / 10,000 / 100,000 条消息历史，固定每条内容大小，测 SQLite 历史重建与记录检索；另测真实 Runtime 恢复较短活跃路径的耗时。注明硬件、记录数、样本数、热缓存及不包含 API 时间。合成压力数据不计真实使用任务。

判定由独立断言检查：目标会话身份、分支中应存在/不存在的标记、模型配置、工具执行结果及原始文件未重复变更。界面声称切换成功不能单独算通过。旧版不支持的路径记录能力缺口；存在可行替代操作时也执行替代路径。

完成后公开报告与聚合 JSON、操作日志、源码/驱动摘要。原始 .aster、SQLite、终端日志位于独立运行目录。不把评测壳放到 exam_project，不将这些材料用于未见训练测试集。
