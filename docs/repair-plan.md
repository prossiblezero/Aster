# 本轮修复与验收

以 `4c3b245` 为修复前版本，保留 v2 报告和失败样本。此次用户已授权实现。
原则：修共享入口；保留单一 Runtime、working memory 与 Hooks；不增加服务、训练框架或上下文自进化。
涉及超过 8 个文件，分模块实现后统一集成。

```text
CLI / TUI / RL step
        |
        v
Runtime ---- Context ---- Provider
  |  |          ^
  |  +------ Memory
  v
工具分发 -- 权限 / Hooks -- 沙箱 -- 工作区
  |
  +---- trace / checkpoint / 独立评测
```

| 问题 | 最小修复 | 验收 |
|---|---|---|
| 停滞误判 | 对比调用与结果，实际文件变更清空停滞窗口 | 多文件空输出写入不停机；真正重复/振荡触发有界恢复 |
| 输入超预算 | 用实际协议请求及工具定义计数 | 12 组预算满足、请求与关键证据保留；不可压缩请求明确拒绝 |
| 历史配对损坏 | 按完整模型调用组裁剪和保存 | 多调用、推理块、恢复后无孤立结果 |
| 工具路由 | 状态工具归 Runtime，文件工具归 WorkspaceTools | todo/plan/diff 和全部工具均有明确可执行路径 |
| diff 基线错误 | 哈希快照与文本基线分开，保存原始基线 | 修改/新增/删除及 resume 后 diff 正确 |
| TUI 自动同意 | 异步明确审批，后台任务与取消 | 无人批准不执行；拒绝/回答/取消均可运行 |
| 持久记忆准入 | 成功观察内容和来源约束，拒绝敏感与临时信息 | 有真 evidence ID 的无关/敏感文本仍拒绝 |
| 回滚污染 | 读取快照也深拷贝 | 回滚后更新再回滚恢复原计数 |
| Stop hook 缺失 | 统一终态收尾且幂等 | 成功/失败/取消均恰好一次；异常不绕过限制 |
| 记忆演化无效 | 来源新鲜度、使用反馈排序及失效淘汰 | 固定演化开关对照；区分召回收益与演化收益 |
| 交互占位 | 接通询问与 worker 消息；权限继承、并发回收 | 回答进入下一轮，worker 不提权、可取消 |
| Provider 诊断 | 分类、脱敏错误与有限瞬时重试 | 无效请求不重试、限流/连接错误有界重试 |
| 评测不足 | datasets 中新增机制与对抗任务 | 原题不削弱；确定性、专项、同题真实模型对照 |
| 后训练接口 | episode 工作区隔离、终态奖励由独立验证器提供 | 重复工具不能刷正奖励；终态不可再次 step；数据不串场 |

实现后运行 conda `aster` 中的 pytest、ruff、全量脚本评测与固定 29 题真实模型双条件评测。
网络错误保留原始尝试；预算计数是本地估计，远端计费 usage 单列。真实评测调用现有 `.env` 中的
网关和 GPT-5.6 Luna；不输出凭证。Chat/Anthropic 在无对应凭证时仅标为协议契约测试。

风险：轻量事实准入只验证来源摘录，不能证明自然语言推理结论；使用反馈不是严格因果归因。
因此不引入语义裁判或自动改写记忆，保留来源、失效及回滚证据。Git 提交可以回退代码；旧评测
产物保留，记忆结构用兼容缺省字段读取；不得通过清空用户记忆解决迁移问题。
