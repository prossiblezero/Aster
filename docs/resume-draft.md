# Aster：轻量代码智能体 Harness

**核心技术：** Python、异步编程、工具调用、上下文管理、分层记忆、状态恢复、沙箱隔离、自动化评测。

**项目描述：** 开发面向本地代码仓库的智能体运行系统，统一模型调用、代码修改、权限控制、任务恢复与结果验证。通过同题对照和模块消融，验证上下文、记忆与运行治理的效果，并提供供后续训练策略调用的独立任务环境。

**核心贡献：**

1. **统一执行流程与工具管理。** 让命令行、交互界面和训练环境共用一套运行逻辑，串联参数检查、审批、执行和记录；组织 26 种工具，默认最多展示 9 种核心工具，其余按需加载。在 12 道函数题的同题对照中，两组均全部完成，核心集合将平均 token 从 27,558 降至 24,430，减少 **11.4%**。
2. **控制长任务的上下文规模。** 将对话、工具定义及协议包装统一纳入预算，按完整调用与结果组裁剪历史，保留当前请求、计划与待办；长正文支持继续分页读取。在 **12 组**代码、日志与中文压力配置中，平均输入由 **18,207 压至 3,352** 个本地估算 token，全部满足预算，当前请求与指定证据均保留。
3. **设计分层记忆与反馈维护。** 会话内保存文件、搜索与测试摘要，文件变化后及时失效；跨运行保存有来源证据的项目事实，通过反馈排序、过期停用和快照回滚维护质量。在 12 条真实模型问答中，关闭/开启长期记忆分别完成 **11/12、12/12**；双方均答对的 11 条，后续工具调用从 **35 次降至 0 次**，token 减少 **65.3%**。另用 6 个固定反馈场景验证记忆维护，目标召回从 **2/6 提升至 6/6**。
4. **保障任务恢复与有界纠偏。** 保存任务状态、完整交互及工作区指纹，恢复时检查文件内容、权限和配置漂移；重复或振荡调用只允许有限次调整，取消时等待子任务退出。在续跑、漂移和恢复控制场景中验证边界；重复与振荡两类消融中，开启恢复后目标达成由 **0/2 提升至 2/2**。
5. **集中管理工具安全与 Hooks。** 统一路径、写入范围、审批和进程隔离，设置执行前、成功后、失败后和停止回调；工具目录同步过滤不可用能力。在重复调用和前置检查异常两类消融中，开启 Hooks 后均阻止了不应执行的动作；**27 个测试工具场景**覆盖真实执行、全跳过、假输出、提前退出及环境错误，防止假通过与记忆误扣分。
6. **建立可复现评测与训练环境接口。** 将 **193 条主任务、69 个机制场景**集中放入数据目录，完成 **205/205 次参考动作回放、97/97 次机制契约检查**；代码修改任务由运行后注入的隐藏测试独立评分。RL 环境每次复制初始仓库，复用生产执行路径，对终态统一评分，成功奖励须同时满足任务要求与独立验证，避免状态串场和通过延迟结束逃避失败评分。

## 面试时解释数字

| 数字 | 实际范围与限制 |
|---|---|
| 工具集合节省 11.4% token | GPT-5.6 Luna，HumanEval/0–11，每题每条件一次；平均工具调用 6.08→5.83。登记 26 种工具，实际还会按权限和回调过滤，`all` 指当前可用全集 |
| 仓库工具对照 | 5 道仓库题两组均完成，核心集合平均 token 47,008→41,174，减少 12.4%；工具调用 15.00→15.80，不能说所有成本都改善 |
| 12 组上下文配置 | 12/24/48/96 条观察 × 代码/日志/中文；输入上限 3,584；本地 tokenizer 测量，不等于真实任务计费减少 81.6% |
| 记忆节省 65.3% | 两组均先做相同的读取/存储动作，再用新 Runtime 问答，源文件仍可读；学习阶段固定，Luna 自主完成后续问答。35→0 是所有后续工具调用，不全是读文件 |
| 记忆反馈 2/6→6/6 | 固定动作与预设反馈，仅证明排序、停用机制按预期生效，不能称为真实任务自进化收益 |
| 恢复与 Hooks | 各 2 个机制消融场景，结果可复现，规模很小，不外推业务成功率；工作记忆和其他安全规则在关闭组仍保留 |
| 262 个任务/场景 | 193 主任务＝12 Harness＋5 仓库＋12 记忆＋164 HumanEval，另加 69 机制场景。12 组配置与 293 项工程测试均单列 |
| 205/205、97/97 | 前者为参考动作经过真实 Runtime 的回放；后者为各开关条件符合预期。关闭机制可以按约定失败，不能把“契约通过”说成 Agent 完成任务 |
| 真实模型最终 57/58 | 固定 29 题、每题两种条件、每条件一次。函数两组各 12/12，仓库各 5/5，记忆关闭 11/12、开启 12/12；不混合条件计算 Pass@3 |

最终批次的唯一失败是关闭长期记忆的 `memory_steps`：模型未读文件，猜测 16，正确值为 17。另有两次命令缺少结尾引号被拒、六次编辑前缺少最新读取被拒，后续均完成任务。这些结果保留，不用最好看的批次覆盖失败。工具次数包含定位、读取、修改、测试和差异检查，不等于回答同一问题的重试次数。

当前已实现 Agent-RL 环境接口，**尚未实施 SFT、GRPO，也没有后训练收益**。内建测试验证面向 Python，其他语言需要对应验证器。真实连接只评测了 Responses；Chat、Anthropic 通过协议契约测试。隐藏评分与候选同 Python 解释器，不宣称完全抗恶意候选篡改；当前适用于可信任务和小规模 rollout。
