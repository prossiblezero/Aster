# Aster：轻量级 Coding Agent

**核心技术：** Python、asyncio、SQLite、Tool Calling、MCP、上下文压缩、分层记忆与自进化。

**项目简介：**面向自然语言驱动的仓库开发，自研支持代码修改、测试验证、跨会话协作与经验复用的本地 Coding Agent，支持方案分支和中断续接，持续复用项目约定与修复经验，减少重复交代项目背景和手动衔接开发步骤的负担。

- **Agent Harness 与独立评测。** 构建统一 Runtime，接入多模型协议与 MCP，支持沙箱执行、测试验收和父子 Agent 协作；从 SWE-bench 等四个开源 benchmark 选题构建开发集，同模型、同预算下，任务通过率为**87.0%**，略优于Codex；**估算成本较 Codex 低 11%**。
- **分层记忆与自进化。** 分离任务状态与长期知识，通过证据提炼、后台整理及反馈召回积累项目经验。在 **跨会话评测集**对照中，后续任务完成率由 **40% 提升至 70%**。
- **上下文管理与压缩。** 按预算压缩历史和工具输出，保留关键状态与调用配对，支持归档回读；采用追加式历史与状态更新复用前缀缓存，benchmark缓存输入占比达 **88.0%**。在 **预置长历史代码题**中，首请求平均压缩 **57.8%**，且**不影响**任务通过率。
- **会话树与任务恢复。** 基于 SQLite 保存会话树、模型配置与恢复点，支持分支探索、摘录交接和多会话后台执行；以持久化调用记录防止不确定写操作重放，采用增量快照与检查点批量落盘控制开销。六类固定工作流的离线对照中，操作数减少**47.8%**。
