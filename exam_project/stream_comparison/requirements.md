# linecounts

从空目录实现标准库 Python 命令行工具 `linecounts.py`，调用方式是 `python linecounts.py INPUT.txt`，必须恰好提供一个输入路径。

以 UTF-8 解码输入文本，逐行调用 `str.strip()` 去除首尾空白；忽略结果为空的行。以剩下的整行文字为键，统计出现次数。区分大小写，不拆分行内单词，不改变行内空白，不做 Unicode 归一化。按 Python 字符串字典序排列键，只向 stdout 输出一个 JSON 对象和换行，值为整数；中文直接显示，不输出 `\u` 转义。空文件和全空白文件输出 `{}`。支持 LF、CRLF、没有末尾换行以及含空格的文件名，不修改输入文件。

成功退出 0，stderr 为空。缺少/多余参数、未知选项、输入不存在、输入是目录或不能按 UTF-8 解码时退出 2；stdout 为空，stderr 给简短错误，不输出 traceback。`--help` 可以显示帮助并退出 0。
