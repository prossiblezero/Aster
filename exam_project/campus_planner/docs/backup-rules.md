# 备份互操作

“导出备份”下载UTF-8 JSON，文件名为campus-planner-backup.json，使用data-contract中的version=1数据包。导出不修改清单。

“导入备份”选择本地JSON文件，按id合并：同id用导入记录替换；新id追加，未出现在备份中的现有任务保留。导入包内部id重复时整包拒绝，不按最后一条猜测。字段非法、版本未知、非法JSON、无效日期或单个文件超过1MiB时整包拒绝；显示错误，原清单和存储均不变。额外字段忽略，不写入HTML。空tasks数组是合法的无变化导入。

稳定项目约定：备份导入先完整校验再一次提交；导入失败不得留下部分记录。标题、课程、备注中的HTML片段按普通文本展示，不能执行脚本。
