# 课业清单

一个无需后端的本地课业管理网页。可以添加、编辑、删除作业，标记完成或恢复，并按关键词、课程和完成状态筛选。未完成作业按截止时间升序显示；早于当前本地时间的未完成作业会标为逾期。

支持将清单导出为 JSON 文件，并在另一台电脑或浏览器中按任务 ID 合并导入；也可以把未完成作业导出为标准 ICS 日历文件。产品不包含账户、日历账户连接或自动跨设备同步。

## 使用

需要 Python 3 和支持 JavaScript 模块的现代浏览器。在项目根目录运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后在本机浏览器打开：

```text
http://127.0.0.1:8000/
```

使用步骤：

1. 填写作业名称、课程和截止时间；备注可留空，然后选择“添加作业”。
2. 在清单中使用“完成”“恢复”“编辑”或“删除”管理作业。删除确认后，页面会提供“撤销删除”按钮；它只恢复最近一次删除的一条任务，并恢复原 ID、名称、课程、截止时间、备注及完成状态。再次删除会替换可撤销记录，成功撤销后该记录即清空。
3. 使用搜索框搜索名称、课程或备注；搜索可以和课程、状态筛选同时使用。
4. 选择“导出日历”，浏览器会下载 `campus-planner.ics`。文件只包含当前未完成作业，不受页面筛选条件影响；截止时间按北京时间转换为 UTC，每项日程持续 30 分钟。可在系统日历或其他支持 ICS 的日历应用中导入该文件。空清单或所有作业均已完成时也会下载合法的空日历。
5. 选择“导出备份”，浏览器会下载 `campus-planner-backup.json`，且不会修改当前清单。
6. 换到另一台电脑后打开本页，在“导入备份”文件输入中选择该 JSON 文件。同 ID 任务会由备份记录替换，新 ID 任务会追加，目标清单中其他任务会保留。
7. 等待页面显示导入完成后再继续操作。空备份不会改变清单；非法、未知版本、重复 ID、字段或日期无效以及超过 1 MiB 的文件会被完整拒绝，原清单保持不变。
8. 空清单时可选择“加载示例”。已有作业时不会加载示例，也不会覆盖现有数据。

## 本地存储与边界

清单保存在浏览器 `localStorage` 的 `campus-planner-v1` 键中，不会发送到服务器。浏览器按站点隔离数据，因此更换浏览器、主机名或端口会看到另一份清单。例如 `127.0.0.1:8000` 和 `localhost:8000` 不共享存储。清除该站点的浏览数据也会删除清单。

“撤销删除”记录只存在当前页面内存中，不写入 `localStorage`；刷新或关闭页面后撤销机会清空。成功撤销会通过原有 version 1 格式保存恢复后的任务，其他任务不受影响。

如果已存数据不是合法 JSON、版本或结构不受支持、字段无效，页面会显示警告并以空清单运行。第一次尝试修改清单时，页面会先询问是否用当前清单覆盖无法读取的数据；取消则不写入，确认后原数据会被替换。本产品当前没有恢复损坏数据的能力。

如果浏览器禁用本地存储、存储访问失败或空间不足，页面会显示“未保存”提示。当前页面内仍可继续添加、编辑等操作，但修改只保留在内存中，刷新或关闭页面后会丢失。导入备份必须成功写入本地存储才会更新页面内清单，否则会报告失败且保持原清单不变。

备份是 UTF-8、`version: 1` 的 JSON 数据包，最多 1 MiB。导入只读取约定字段，多余字段会忽略；任务名称、课程和备注中的 HTML 片段始终按普通文本显示。备份文件由用户自行转移和保管，应用不会上传文件，也不提供服务端副本或自动同步。

日历导出同样只读取当前页面内的清单，不会修改任务或 `localStorage`，也不会连接日历账户或上传数据。ICS 是一次性下载文件；之后修改任务不会自动更新已导入的日历事件，需要重新导出并由所用日历应用处理同 UID 事件。

## 测试

无需安装依赖。使用 Node.js 内置测试运行器执行纯逻辑测试：

```bash
node --test
```
