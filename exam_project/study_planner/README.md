# 期末复习安排器

一个无需账号、后端或构建工具的中文期末复习计划小网站。课程、时间设置和最近一次计划会保存在当前浏览器的 `localStorage` 中，刷新页面后仍可继续使用。

## 本地预览

直接双击 `index.html` 通常即可打开。若浏览器对本地文件的脚本或存储策略有限制，也可以在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库，把 `index.html`、`styles.css`、`app.js` 和 `README.md` 放在仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**，选择默认分支的 `/ (root)`，点击保存。
4. 等待 GitHub Pages 完成部署，再使用页面显示的公开地址。

项目没有依赖、打包步骤或 CDN，仓库根目录的 `index.html` 就是入口文件。

## 使用方式

1. 设置可调整的 `开始日期` 和 `每日上限（小时）`。
2. 填写 `课程名称`、`考试日期`、`剩余小时`，点击 `添加课程`。
3. 课程全部录入后点击 `生成计划`。
4. 课程表中的 `编辑` 会把数据回填到同一组输入框；完成修改后点击 `保存修改`。删除课程需要确认。

## 排程规则与限制

- 每门课程只能在 `开始日期` 到考试日前一天之间安排，考试日期当天永远不会排入计划。
- 每个日期的所有课程合计不超过每日上限；任何课程不会被安排超过它填写的剩余小时。
- 计划按考试日期较近的课程优先分配当天容量，同一天再按课程名称排序。每次重新生成都会基于当前课程和设置生成全新的计划。
- 容量足够时，每门课程安排总小时数与剩余小时完全相等。
- 容量不足时，页面保留能安排的部分，并在可见状态区域和概览中显示“不足”及缺少的总小时数；不会超出每日上限、挪到考试日或静默丢弃课程。考试日等于或早于开始日期的课程会产生全部小时不足。
- 课程名称不能为空；考试日期必须有效；剩余小时和每日上限必须是大于 0 的有限数字，可使用小数，例如 `1.5`。
- 数据只保存在当前浏览器。清除浏览器站点数据会清除课程和计划，项目不提供跨设备同步。

## 自测清单

可在本地按以下场景检查：

- 添加多门课程，生成计划并确认表格有 `日期`、`课程`、`小时` 三列。
- 设置每日上限为 `1.5`，确认任何日期总和不超过 `1.5`。
- 设置开始日期为考试日前一天，确认最多只排这一天；设置为考试日当天，确认显示不足且没有计划行。
- 输入空课程名、无效日期、`0` 或负数小时，确认无法保存并看到错误提示。
- 修改开始日期、每日上限或课程后重新生成，确认旧计划被替换且不足提示在完整计划成功时清除。
- 刷新页面，确认课程、设置和计划仍存在；在 390px 宽视口操作，确认页面不整体横向溢出，表格可独立横向滚动。

无运行时依赖。修改后可运行以下自动测试，测试会加载并执行 `app.js`，使用最小 DOM 替身覆盖删除最后一门课程后重新生成及刷新持久化场景：

```bash
node --test tests/verification.test.js
```

也可以用 `node --check app.js` 做单独的 JavaScript 语法检查。
