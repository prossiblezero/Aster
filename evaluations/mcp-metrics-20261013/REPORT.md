# MCP 指标实测（2026-10-13）

计划 8 类任务 × 2 次重复 × 2 组，共 32 次；实际记录 32 次真实模型运行。模型为 `gpt-5.6-luna`，使用现有 Aster Runtime、GitHub 官方只读 MCP 和自编文件 MCP。未测试备用服务器。

按需加载相对全量加载：首轮 Schema 体积变化 **-69.3%**，整任务已报告 token 变化 **+18.9%**，平均耗时变化 **+38.0%**。工具定义的缩减与整任务成本必须分别观察：发现、加载产生额外模型轮次，每轮仍需携带系统指令、任务和已有历史。

Schema token 包含两组共同保留的内置工具。MCP 业务调用耗时不包含目录发现及工具加载。“符合约束”采用冻结脚本的严格规则；7 次成功调用未被它计入，其中 6 次是额外查看工作目录，1 次使用 GitHub 接受的提交 SHA 前缀。这些不能等同于选错工具，所有明细保留在 `results/`。

实际有 1 次服务端参数范围错误：`read_file(limit=10000)` 超过 2000 上限，返回 `mcp_tool_error`；模型改为 2000 后成功。该限制没有体现在工具 Schema 的数值边界里，因此不能用客户端 `invalid_arguments=0` 宣称没有参数错误。

## 检索质量

冻结目录上的 14 个工具意图，每种查询形式各 14 条；每题一个相关工具，因此 Recall@K 等于 Hit@K。

| 查询 | Recall@1 | Recall@3 | Recall@5 | MRR |
|---|---:|---:|---:|---:|
| 英文自然表达 | 92.9% | 100.0% | 100.0% | 0.964 |
| 中文自然表达 | 0.0% | 0.0% | 0.0% | 0.000 |
| 工具原名正向对照 | 100.0% | 100.0% | 100.0% | 1.000 |

当前检索直接匹配名称和描述中的词，中文查询与英文目录没有共同词。中文任务能否完成还取决于模型是否使用英文查询或空查询枚举；上述 0% 只衡量检索模块，不能等同于中文任务成功率。
模型实际发现查询及次数：`{"": 11, "issue": 2, "read repository file commit contents": 1, "repository search repo get": 1, "repository search": 1}`。

## 幂等

真实 filesystem MCP 的 10 次独立写入，追加 20 次重复请求（同会话及恢复后各 10 次）：**20/20 返回已保存结果**，10/10 个文件的内容和修改时间保持不变；**10/10 次参数冲突被阻止**。本次未观测到重复文件副作用，不能外推为分布式 exactly-once 保证。

## 用量与延迟的证据边界

两组共记录 146 次 HTTP 尝试，其中 29 次未返回 usage。主表保留重试耗时；token 仅汇总 API 返回的数字，不能视作完整账单。其中 `files_create--eager--1` 完全没有用量记录，对已报告 token 求和贡献为 0，真实消耗未知；首轮 input token 均值只使用有用量记录。

共 117 次成功 HTTP 尝试均报告响应模型为 `gpt-5.6-luna`；其余没有返回模型名。中途曾因完全无用量失败暂停，经单次接口检查恢复后，仅补跑未开始的任务；没有重跑失败项，检查请求的 4,396 token 独立记录，不计入主表。详见 [PROTOCOL.md](PROTOCOL.md)。

| 用量字段（整组累计） | 全量加载 | 按需加载 |
|---|---:|---:|
| input_tokens | 476,682 | 566,701 |
| output_tokens | 3,763 | 4,612 |
| cache_read_input_tokens | 273,408 | 292,352 |
| total_tokens | 480,445 | 571,313 |

另有 **6 对**任务的两组全部 HTTP 尝试均成功且返回用量。该辅助子集平均 token 为 38,817 / 42,441，平均耗时为 38.1 / 50.8 秒（全量/按需）。筛选只取决于传输和用量完整性，主结果仍包含全部 32 次已记录运行。

缓存命中受组别顺序、工具定义变化及服务端缓存状态影响；两组虽交错运行，但没有控制服务端缓存。并发两对任务的公网耗时包含排队和网络波动，不能把全部差异归因于 MCP 本身。每组至多 16 次短任务，100% 样本成功也不代表生产可靠率。

## 复核与复现

`audit.json` 核对全部模型工具调用与执行结果一一对应、轨迹哈希、Runtime 与请求用量账本一致；验收器对已知正确答案放行，对空工具证据、错误答案及错误文件状态拒绝。Ruff 和已有 3 项操作幂等回归通过。运行方法、事前约定及静态统计修正见 [PROTOCOL.md](PROTOCOL.md)。

数据入口：[summary.json](summary.json)、[pairs.json](pairs.json)、[retrieval.json](retrieval.json)、[idempotency.json](idempotency.json)、[freeze.json](freeze.json)、[results](results/)。原始请求与会话保存在 `artifacts/private/mcp-metrics-20261013`，未包含于 Git 跟踪文件。
