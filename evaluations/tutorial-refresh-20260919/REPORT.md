# Aster 自主维护教程与教学网站

日期：2026-09-19。用户要求让Aster自己核对当前实现，更新教程Markdown和教学网站。起点为`1c67fbc`，只做文档维护，不改Aster核心，不开展插件重构或训练。

交付结论：Aster完成16章教程及网站的修订，经独立语义复核、17个原生实验、25项网站相关离线测试和13项浏览器检查验收通过。期间有操作员中止、明确反馈和追加预算，属于人工审查后完成的维护任务，不是一次无干预自主成功。

## 执行边界

通过公开Aster CLI和当前冻结源码运行，使用用户指定的aster Python、现有main profile及Responses流式，128000总上下文、32768输出预留、240秒尝试时限。工具在required沙箱中执行，网络关闭，写入限定为教程、当前配置/Skills说明、根README和learn_web。Memory、Worker和依赖复用关闭。完整设置与种子身份见`settings.json`、`seed-manifest.json`，启动请求见`task.md`。

候选是隔离维护副本，真实凭证在副本外；没有把评测文件放入exam_project。操作员只准备运行环境、检查清单、反馈和独立验收；课程正文、实验和网站修改由Aster完成。源码、产品测试、数据集、历史报告与原始轨迹不属于修改范围。最终采纳前逐文件比对边界与来源。

## 首次发现与人工纠偏

原教程00–08实验通过，09因错误信息现在带具体配置字段与说明而旧的完全相等断言失败；10–15分别通过，见`baseline-examples.json`。站点静态检查虽通过，正文仍有过时内容：同轮工具全串行、Skills不支持SKILL.md包、活动正文每轮重新读取、旧恢复入口与计数规则等。独立核对清单为`review-checklist-00-07.md`与`review-checklist-08-15.md`。

首次Aster运行发现工具PATH没有rg，且在外层沙箱内运行教程时缺少tiktoken词表缓存、嵌套隔离受限。它随后尝试屏蔽tokenizer并将required实验降为best_effort。操作员在134.966秒时中止，要求撤回削弱实验的改动，见`environment-feedback.md`；此次51工具步、15模型轮及已报告758463 tokens保留，取消尝试的未报告usage不按零计。这是维护过程中的失败，不写成自主修复成功。

环境纠偏后的续跑完成网站构建和正式静态检查，但只修入门环境、04和09，仍漏原任务的大部分内容。Runtime的completed/verified仅表示其通用完成条件与6项静态测试通过，不能证明文档事实准确或16章已充分审查。操作员拒绝该候选，保存`content-review-first.json`及本地`snapshots/content-incomplete/`，再给`content-review-feedback.md`逐项审查反馈。该续跑58工具步、25模型轮、365.234秒、已报告1685801 tokens全部保留。

追加修订仍用原候选和相同Aster/模型配置，另记录160步/90轮/1800秒的维护预算。此任务不是预注册因果评测，不用重复运行/人工反馈后的最终结果宣称首次成功或新版本普遍收益。

第三轮`content-revision`完成了主要章节的初步更新，但在160工具步、62模型轮、1079.222秒后以`step_limit`停止，已报告2921205 tokens。期间出现各4次`patch_nonunique`/`fresh_read_required`、两次未报告usage的传输失败，以及站点测试的旧流程图节点计数不匹配。模型尝试合并图节点、再次构建，但停止时正式验证仍为missing。它还把构建生成的已引用报告副本误当成不应进入候选的历史证据；操作员澄清站点引用副本属于交付产物，原始证据仍不得改。

独立审查发现新段落与旧段落并存导致矛盾：跨协议恢复、祖先观察、Memory入库归属仍不一致；Skills源码节选含非法Python省略写法；构建器另会注入过时的持续会话说明。操作员给出`semantic-review-feedback.md`，以140步/70轮/1500秒单独续跑。反馈允许合法图变动同步站点固定计数，但不允许删除结构比较断言。该反馈和追加预算均属于人工干预，不能记作Aster首次自主发现并解决。

第四轮`semantic-repair`以92工具步、27模型轮、424.133秒、已报告1515295 tokens完成正式静态测试。图的边数因真实流程更新由97变98，Aster同步了这一项固定计数，保留源码与渲染结果的完整节点/边/顺序比较。独立复核关闭了大部分发现，但09章仍错误地把上下文/输出预算列作不能改变的安全项，并把省略历史转换的路径称作真实入口。因此另给`resume-review-feedback.md`进行小范围订正，未直接由操作员改正文。

原生实验独立运行在第四轮期间完成：16章共17个标记实验（14章含2个）全部通过，耗时6.145秒；各代码块执行前后哈希均一致，04实际使用`landlock+seccomp`。原始输出、导入路径和逐块哈希保存在`native-examples.json`/`.txt`，不调用模型API。最终比对发现09随后增加了adopt边界注释，代码块哈希改变；单独原生补验该章通过，见`native-example09-final.json`/`.txt`。其他16块与已执行版本一致。没有把旧哈希的通过记录直接冒充最终版本通过。

第五轮`resume-correction`只修09入口和模型预算的说明，10工具步、7模型轮、156.255秒、已报告136010 tokens，完成重新构建和6项正式静态测试。最终09及其他章节哈希与审查者核对版本一致。
