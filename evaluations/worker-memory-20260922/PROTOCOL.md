# GPT Worker 与 Memory 真实维护评测（运行前协议）

产品源码冻结于 `7462e8b`，不修改 `src/aster`、训练接口或委派实现。使用 Conda aster，显式 `PYTHONPATH=src` 并核对 `aster.__file__`、源码逐文件摘要。模型、地址和凭证从现有 `.env`/进程环境读取；不更换模型、网关或接入 DeepSeek。公开配置不包含地址明文或凭证。

目标是量化具体使用场景的收益，不预设功能一定有正收益。参考 [OpenAI evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices)：固定任务、按实际场景选择指标、保留失败与边界样例。该链接仅作为方法参考，任务和判分由本仓库定义，不调用 Evals 平台。

## Worker：12 次真实尝试

6 个合成小仓库任务，每题独立初始化、每条件一次。4 个可独立拆分的任务：CSV 账目、访问日志报告、笔记导出、文件索引；1 个共享接口依赖任务；1 个共享文件任务。新任务不等于真实用户工作分布，也不宣称统计泛化。

同一需求分别使用 `max_workers=0/2`，工具集均为 core，模型自行决定是否委派和如何划分；不注入预定子任务、不代替模型轮询或整合。顺序按题交替 off/on。未委派仍计入开启组，不用观察到的成功子集替代整体结果。父任务完成后必须通过外部独立验收，子任务单独完成不等于整题完成。

主要指标：整题通过数、端到端墙钟时间（不含事后评分）、父子全部已报告 token、实际委派数、子任务完成数、协调调用数。独立与依赖/共享文件任务分开报告，另列共同通过题的配对时间和成本。范围冲突、取消和残留修改只报告实际观察；若没有自然触发，不写成拦截率 100%。并行仅在同一个被测父任务内部发生，不并行运行不同试题。

## Memory：2 次学习 + 18 次真实维护

Parcel 与 Agenda 两个项目。各先运行一个只读真实 GPT 熟悉任务，允许它选择保存摘录，记录从读取到存储的实际动作；不手工种入、不要求保存成功才继续。学习完成的同一初始代码、资料、记忆与来源 trace 复制给三个条件：

- off：关闭长期记忆。
- basic：开启记忆，关闭 evolution 和 auto_dream。
- maintained：开启记忆、evolution、auto_dream。

每组依次执行三次新 Runtime/新会话维护：实现导出、新增汇总/提醒、适配文档中变更后的 wire 协议。每轮源文档始终存在可读；最终轮在三组同一位置修改同一个来源文档，旧来源记忆应失效。每组代码和记忆随实际运行演进，不回填失败产物；这是连续工作流的总效果，后续单轮不作为只改变一个开关的独立因果试验。初始学习费用单列；基础 off/on 的总流程成本都列入一次共享熟悉任务费用，同时列后续复用成本。真实自动保存、召回、检索、测试反馈和 Dream 单独报告。

主指标：每轮和累计独立代码验收、查找/读取来源次数、全部输入和总 token；补充维护前后记忆状态、过期来源是否出现在实际首请求及代码是否仍使用旧契约。仅减少 `read_file` 不自动等于少查资料，还需检查 search/run_shell 是否代替读取。反馈维护是否改善召回与代码正确性根据实际记录判定；如果没有坏记忆、反馈未改变 Top-3 或基础失效机制已经足够，结果应为“本批未建立维护增益”，不能用人工反馈制造真实收益。模型生成的测试反馈不等于对每条记忆的因果归因。

## 配置、停止与完整消耗

统一 Responses 流式，总上下文预算 64,000、输出预留 8,192、HTTP/流式尝试超时 120 秒、沙箱 required、approval auto、工具进程无网络。只读工具并发为 1；不提供 Skills、不复用依赖环境。学习阶段只读，其他条件正式完成须观察、编辑并验证。

每次任务 600 秒；父任务最多 60 步/40 轮，Worker 保留产品自带的 12 步/12 轮。评测侧共享 Hooks 对所有父子已通过前置检查的工具动作限制 60 次，并在请求边界限制整个任务最多 40 次逻辑模型调用、已报告总 tokens 达到 500,000 后停止发起新调用。Token 限制不是账单硬上限：在途请求及一次响应可能超出，缺失 usage 的 HTTP 尝试消耗未知。父子任务使用相同模型配置，全部记录进入 ledger，不以父运行的 usage 冒充总成本。

保留所有 HTTP 尝试分类、响应模型标签、原始数值 usage、归一 usage、请求摘要和覆盖率。缓存/推理 token 是子集，不重复累加。无网关价格与账单，仅报告已报告 tokens，不报告金额。服务端缓存、负载和采样不可完全控制；各条件一次不宣称稳定加速或统计非劣。

不进行人工修复/提示补充或任务级选择性重试；沿用产品自带的传输重试。评分器先运行未实现/参考/逐模块删除对照，均正确才开始真实任务。失败记录不覆盖。若基础设施失败无法继续，应保留已发生请求，记录修订后另开批次。
