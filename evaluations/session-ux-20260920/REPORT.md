# 会话管理实现与操作评测

实现基线 `a3f338b`，正式候选源码 `1fee848`。本次实现类型化会话树、稳定位置导航、带来源的摘录交接、历史模型配置恢复和多个独立会话的终端切换。不同工作目录可后台运行，同目录执行使用文件锁，取消与流式输出按所属会话分发。旧 JSON checkpoint、run ID 和训练接口保留；`src/aster` 根目录仍只有 5 个 Python 文件。

## 实测操作收益

六类工作流各三个内容变体，新旧各一次：**36 条脚本记录，两版均 18/18 完成**。变体不是独立用户，也不代表 18 类不同任务。调用真实 Runtime、SQLite、TUI 命令和选择器，模型为离线替身；人工阅读、思考和输入时间没有采集。

| 工作流 | 旧版规定路径操作数／次 | 新版规定路径操作数／次 | 结果解释 |
|---|---:|---:|---|
| 找到近期 20 条以外的旧工作 | 5 | 2 | 旧版查看历史后到文件中查找，再复制／粘贴编号恢复；新版搜索会话后选择 |
| 保留 A 方案并从祖先创建 B 方案 | 4 | 2 | 历史列表、复制／粘贴编号、恢复 → 树搜索并选择 |
| 模型改变后返回原位置 | 5 | 2 | 旧版先手动恢复模型再恢复运行；新版随位置恢复配置 |
| 带回探索结论继续 | 6 | 2 | 旧版恢复祖先并手动复制／粘贴结论；新版在树中显式选择带入摘录 |
| 最近一次已知中断后恢复 | 1 | 2 | 旧版 `/resume latest` 一步；新选择器两步。新版仍保留同样的一步命令 |
| 在两个工作区任务间来回切换 | 2 | 2 | 旧版切换两个终端，新版在一个 TUI 内切换，两者都可用 |

按运行前登记的规则，命令提交、选择确认、复制和粘贴分别计一步；外部查找／终端切换单列。共同的预置历史和新增需求不计导航开销。脚本实际调用命令、剪贴板和选择器，但没有模拟每个按键，也没有证明这就是所有用户的最短路径。

三个变体合计 **69→36 次，减少 47.8%**。这是规定工作流的操作数减少，不等于人工耗时减少 47.8%。保持在当前 TUI 内、无需外部文件查找或另一个终端的完成数为 **12/18→18/18**；旧版通过替代路径仍能完成全部工作，不称其任务成功率更低。

三次摘录交接需要手动补充的背景为 **171→0 字符**，每次旧版固定 57 字符。新版摘录也占上下文；这不是 token 节省，更不是模型总结准确率。它仅说明这些固定事实的交接不再需要用户重贴背景，独立断言确认目标上下文含预期事实。

[原始旧版记录](baseline.json)、[原始新版记录](candidate.json)包含所有操作、验证结果、源码清单与摘要、导入路径和驱动摘要。[成对汇总](comparison.json)保留逐条数据。开发和中间修正批次位于本机 `/tmp/aster-session-ux-pilot-*`、`/tmp/aster-session-ux-formal-candidate*`，未将失败选择性移除后合并计算；最终候选完整重跑全部 18 条。

## 本地性能

环境为 Linux、Intel Core Ultra 9 285K，使用 Conda aster Python。性能批次源码为 `4daaa13`，其后 `1fee848` 仅修正 Worker 的执行锁身份，不改变被测历史重建与 checkout 路径。合成消息每条包含编号及 128 个 `x` 字符；每组先热身一次，再完整记录 30 次。数据库记录还包括起点、模型配置和 checkpoint，因此记录总数比消息数多 4。[完整样本](performance.json)保留 p50、p95、全部耗时、机器与源码信息。

| 消息数 | 整条历史重建 p95 | 短祖先路径重建 p95 | 全部记录读取 p95 | SQLite 文件大小 |
|---:|---:|---:|---:|---:|
| 1,000 | 10.73 ms | 5.56 ms | 12.91 ms | 544,768 B |
| 10,000 | 52.08 ms | 7.51 ms | 58.90 ms | 5,087,232 B |
| 100,000 | 571.38 ms | 5.07 ms | 674.63 ms | 50,761,728 B |

单独测量短历史的实际 `Runtime.checkout()`（含预检、状态安装和持久化），30 次 p95 为 **24.51 ms**。十万条历史的数字只测存储层历史重建，不是十万条历史的完整 TUI 切换时间；也没有拿它和模型推理时间比较。测试是热缓存，未量化冷磁盘和峰值内存；合成数据没有真实工作中的大量文件快照和工具输出。

## 实现成本与边界

Python 产品源码 **50→53 个文件，9704→10455 行**；本次是功能扩展，不声称代码瘦身。三个新增模块分别负责树存储、恢复预检和界面导航，复用原 Runtime、ContextBuilder、checkpoint 校验、Textual 和标准库 SQLite；未增加产品依赖，也未在 exam_project 放评测壳。

分支选择不回滚文件；自动摘录有 12,000 字符上限且明确标记截短，不是模型生成摘要；长期记忆仍是有证据的文件摘录，不会自动收录任意对话。不同目录的记忆不会自动共享。旧 checkpoint 只能导入其保留的历史，无法补回旧版本已经覆盖的内容。完整说明见 [会话使用文档](../../docs/sessions.md)。

SQLite 快照包含原有运行状态，长期大量恢复点的磁盘增长尚未做回收策略。选择器一次显示最多 300 个匹配位置，可继续输入关键词筛选；底层列举当前仍读取全会话记录。未把这些限制包装成无限规模能力。

```bash
conda activate aster
python evaluations/session-ux-20260920/run.py --source /tmp/aster-session-baseline-20260920 --variant baseline --output /tmp/aster-session-recheck-baseline
python evaluations/session-ux-20260920/run.py --source /home/dzh/Aster --variant candidate --output /tmp/aster-session-recheck-candidate
python evaluations/session-ux-20260920/performance.py --output /tmp/aster-session-recheck-performance
python -m pytest -q
python docs/learning/run_examples.py
```
