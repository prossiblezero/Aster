# 固定十题比较协议

- 数据固定为两个 `datasets/subagent-*` 清单中的十题、80 个行为问题；源码按公开 URL 和 SHA-256 下载。
- `freeze` 保存当前 `src/` 快照、执行器、配置身份、依赖版本、oracle 及任务顺序，不访问旧 Aster 提交。
- 每次尝试使用全新工作区；同题同次 Solo/team 成对，按固定次序交替运行。
- 团队共享最多 36 次模型调用、60 次已接纳工具动作、300,000 已报告 token 和 600 秒；未知 usage 不当作零消耗证明。
- `adaptive`、`two_children`、`parent_child` 独立冻结，不能跨条件拼成重试；未实际派工不解释为子路径收益。
- 评分基于实际执行 oracle 与源码引用位置，最终 JSON 解析失败、超预算和服务失败都留在分母。
- 比较同时报告严格整题通过、行为事实、解析情况、父子用量与时间。共同成功或完整用量配对只是补充视角。
- 结果与原始轨迹留在本地，不随代码发布；任务已参与开发，不能声称未见测试集。
