# tagmerge

工作区已有 `fixtures/` 下六个小 JSON 数据文件。请先阅读这些输入，理解跨文件出现同一条目标识及标签的情况，再实现标准库命令行工具 `tagmerge.py`，提供 README、示例与 pytest 测试，并实际执行测试。

调用 `python tagmerge.py DATA_DIR`，必须恰好给一个目录路径。只读取该目录直接包含的 `.json` 文件，不递归，不处理其他扩展名。每个文件是 UTF-8 JSON 数组；每条记录必须是对象，具有 `id` 和 `tags` 字段，可以有无关额外字段。`id` 是去除首尾空白后非空的字符串；`tags` 是字符串数组，各标签也必须去除首尾空白后非空。允许空标签数组。不要改变大小写或做 Unicode 归一化。

合并所有文件中同一 `id` 的标签并去重，输出 JSON 对象，键是条目标识，值是标签列表。对象键和每个标签列表均按 Python 字符串字典序排序，中文直接输出而不使用 `\u` 转义。没有 JSON 文件或只有空数组时输出 `{}`。成功退出 0，仅 stdout 输出一个 JSON 对象及换行，stderr 为空。

缺参、多参、未知选项、目录不存在、参数不是目录、文件不是合法 UTF-8/JSON、顶层不是数组、记录/字段类型错误或空白 id/标签时退出 2；stdout 为空，stderr 给简短错误，不显示 traceback。`--help` 可以退出 0。不得修改任何输入文件；保留工作区六个原始 fixture。用实际 fixture 演示运行，不要把这些具体数据写死在实现中。
