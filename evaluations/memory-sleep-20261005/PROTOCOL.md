# 自动学习与异步 Dream：固定十题对照

2026-10-06，运行前固定。基线为 `baseline-sources.zip`，包含本轮改造前的未提交代码；两组都启用 Memory、Evolution、Dream。新版另存源码快照。沿用 `.env` 的模型与协议，不复制凭据。

十道真实模型任务：报表时区、金额计算、两次补充 CSV 约定、用户更正重试规则、三文档归纳、来源过期、支付修复迁移、测试命令迁移、时区适用范围、预算受限的清理函数修复。学习提示没有“请记住”，也不注入记忆；每轮混入一个明确临时标签。使用前一轮内部开发题的代码与行为检查，不能称为未见测试集。

每题每组只运行一次。普通任务每阶段最多 30 个工具步骤、20 次模型请求、200,000 tokens；第十题后续阶段为 8 次请求、80,000 tokens，检查预算内交付。模型上下文 32,768、输出 4,096。新版维护每批本地输入估算最多 4,096、输出限制设为 768，计入同一预算；CLI 同样先完成前台，再给后台最多 15 秒，超时取消并留下待处理材料。普通项目文件保留到新会话，隐藏检查不进入模型工作区。

任务成功要求后续阶段正常完成并通过全部独立行为检查。另列功能通过、两阶段都完成、学习/后续/维护/总 token、工具次数、前台与收尾耗时。维护 token 是总数的子集，不重复相加。usage 缺失单列，保守预算预留不能当作实际计费。所谓经验迁移，限定为成功后续任务召回过前阶段保存的记忆，不证明成功仅由记忆造成。

并行生成、取消恢复、整理途中更正、原子提交与 API 失败使用 `tests/test_memory_maintenance.py` 的受控机制检查：真实 Runtime、文件、执行事件，加确定性模型输出。它们不计入十题模型成功率。以这种方式避免把随机网络时序当成能力题或为时序重复付费。

保留每次尝试的摘要、压缩 trace、产物、源码及题目哈希。不因结果未达目标而调参重跑或替换失败样本。
