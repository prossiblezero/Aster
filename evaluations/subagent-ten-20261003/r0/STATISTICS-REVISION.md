# 统计修订记录

20 个预定回合全部结束后，保留原始请求、结果、FREEZE 和原驱动，再修订统计。缺失 request/HTTP usage 的配对，其 token 与父输入比率改记 null，不参与中位数。总 token 仍是已报告量，新增完整性字段；存在缺失时它只是下界。没有重跑或丢弃任何回合，没有改变原始分数。

原始驱动及其全部哈希依赖保存在私有 `r0/original-harness/`，原摘要、配对、结果和诊断保存在 `r0/original-*.json`。原 FREEZE 继续指向原始哈希。后续轮次冻结新驱动，并各自保存完整驱动快照；重放历史轮次应恢复相应快照后执行。

另为后续回合包装历史评分入口：畸形引用符号导致的 TypeError 记为格式失败并保存结果，不让整个批次退出。正常回答沿用原评分，r0 的全部原始分数经离线复算保持不变。
